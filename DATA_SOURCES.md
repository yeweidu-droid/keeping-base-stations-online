# Data sources

## OpenStreetMap extracts

`sim/data/osm_luding.json` and `sim/data/osm_xuwen.json` contain roads, settlements, and facilities of the two study areas. They were retrieved through the Overpass API with the query in `sim/fetch_osm.py`. The files record the state of the OpenStreetMap database on 30 September 2026 (`osm3s.timestamp_osm_base` in each file).

| File | Area | Bounding box of the query (south, west, north, east) |
|---|---|---|
| `osm_luding.json` | Luding County, Sichuan, China | 29.35, 101.85, 30.25, 102.45 |
| `osm_xuwen.json` | Xuwen County, Guangdong, China | 20.20, 109.90, 20.62, 110.60 |

The experiments use the part of the Luding extract inside 29.40 to 30.12 degrees north and 101.95 to 102.42 degrees east, as set in `sim/scenario.py`.

## Generated inputs

All other inputs are generated by `sim/scenario.py` from the OpenStreetMap extracts and the random seed: station sites, importance weights, demand, power consumption, battery endurance, microgrid partition, damaged road segments and their reopening times, UAV launch sites, and UAV service fractions. The parameters are listed in the paper and its supplementary material.

## Result files

`sim/results/` holds one JSON file per run. These files were produced by the code in `sim/` and are the source of every number, table, and figure in the paper.
